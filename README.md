# PortScanner

## Description

A Python-based Port Scanner developed using Socket Programming on Kali Linux.

## Features

* Scan TCP ports
* Detect open ports
* Fast scanning
* Banner grabbing support
* Simple command-line interface

## Technologies Used

* Python 3
* Socket Library
* Kali Linux

## How to Run

```bash
python3 port_scanner.py
```
